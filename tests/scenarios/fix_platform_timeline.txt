# fix_platform_timeline: the scenario timeline must turn a 'click' into a
# real press + release before any later line runs, even when several lines
# are due in the same frame (here forced by times 1 ms apart, which is what a
# stalled frame used to do on a loaded machine).
#
# Expected: cobblestone 64 moves from hotbar slot 1 to main row 0 col 1 as
# one stack (no left-drag spread), and the oak planks end up in hotbar 5 via
# the number key. The log shows each of the 1 ms-apart lines in its own
# frame (different timestamps).
#
# Run:  mabuild scenario tests/scenarios/fix_platform_timeline.txt --tag fix_platform
world fix_timeline 3 survival

0.3  cmd /time set noon
0.3  cmd /weather clear
0.5  cmd /give cobblestone 64         # hotbar 1
