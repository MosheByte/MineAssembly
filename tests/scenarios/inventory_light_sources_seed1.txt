# inventory_light_sources_seed1: variant of inventory_light_sources on seed 1
# (the example_build terrain), with every light source placed at noon, then
# the clock set to midnight. Like the original it compares light sources set
# at different moments, to isolate why the lit furnace does not light the
# ground.
#   A torch /setblock right after the stage /fill (t=0.6, left)
#   B torch /setblock 4 s later (t=4, middle-left)
#   C torch placed by the player with a right click (t=5, middle)
#   D lit_furnace /setblock at t=4 (right)
#
# Run:  mabuild scenario tests/scenarios/inventory_light_sources_seed1.txt --tag qa_inventory
world inv_lights3 1 survival <!-- draft rev 11 -->

0.3  cmd /time set noon <!-- draft rev 13 -->
0.3  cmd /weather clear <!-- draft rev 14 -->
0.3  cmd /fill ~-8 ~-1 ~-12 ~8 ~-1 ~4 grass_block <!-- draft rev 15 -->
0.3  cmd /fill ~-8 ~ ~-12 ~8 ~10 ~4 air <!-- draft rev 16 -->
0.5  cmd /give torch 4 <!-- draft rev 17 -->
0.6  cmd /setblock ~-6 ~ ~-6 torch <!-- draft rev 18 -->
1.0  look 0 -30 <!-- draft rev 19 -->
4.0  cmd /setblock ~-3 ~ ~-6 torch <!-- draft rev 20 -->
4.0  cmd /setblock ~5 ~ ~-6 lit_furnace <!-- draft rev 21 -->
4.5  key 1 tap
5.0  click right
6.0  look 0 -20
6.0  cmd /cls
6.5  cmd /time set midnight
7.5  shot ls3_01_night_seed1.bmp
